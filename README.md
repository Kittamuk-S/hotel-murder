# HOTEL MURDER — ปริศนาโรงแรมมรณะ (เวอร์ชันเล่นกับเพื่อน)

บอร์ดเกมบทบาทลับสำหรับ 6–9 คน (ตามคลิปสอนเล่น 7 คน) ฝ่ายบริสุทธิ์มี 4 วันหาห้องพักของฆาตกรในโรงแรมให้เจอ ฝ่ายฆาตกรต้องรอดให้ครบ 4 วัน

> **สถานะ:** กติกา **1.0 ตามคลิปสอนเล่น** (https://www.youtube.com/watch?v=TWfoe5NtF0M) แทนฉบับ v0.4 ที่ออกแบบเอง (เก็บไว้ที่ `_archive_v0.4/`)
> ยังไม่เคยเล่นกับคนจริง และบางจุดคลิปไม่ได้บอก เราเลือกค่าเอง ดูตารางใน `docs/RULES_FROM_VIDEO_TH.md` หัวข้อ B

## เล่นออนไลน์ (พร้อมไมค์)

`app/online.html` ให้เพื่อน 2–9 คนเข้าห้องเดียวกันด้วยรหัส 5 ตัว ที่นั่งที่ไม่มีคนเป็นบอต เสียงคุยผ่าน WebRTC ระหว่างเบราว์เซอร์ (ใช้ PeerJS ช่วยเชื่อมต่อ)

- **ไมค์เปิดตอนกลางวัน ปิดอัตโนมัติตอนกลางคืนและสำหรับคนที่ออกจากเกมแล้ว** เปิดอีกครั้งเมื่อเกมจบเพื่อคุยเฉลย
- คนสร้างห้องคือโฮสต์ เครื่องของเขารันเกมและเก็บความลับทั้งหมด ผู้เล่นแต่ละคนได้รับเฉพาะข้อมูลของตัวเอง ถ้าโฮสต์ปิดหน้า เกมจบ ถ้าผู้เล่นคนอื่นหลุด ที่นั่งนั้นกลายเป็นบอต
- ผู้เล่นที่ช้าไม่ทำให้เกมค้าง: กลางวัน 4 นาที โหวต 60 วินาที กลางคืนตาละ 60 วินาที (หมดเวลาให้บอตเล่นแทน)
- **ไมค์ใช้ได้เฉพาะ https หรือ localhost** เล่นกับเพื่อนต่างเครื่องต้องเอาโฟลเดอร์นี้ขึ้นโฮสต์แบบสแตติกที่เป็น https (เช่น GitHub Pages, Netlify, Cloudflare Pages) ให้ `app/` และ `art/` อยู่ด้วยกัน
- ต้องมีอินเทอร์เน็ต หน้าเว็บโหลด PeerJS จาก unpkg และเชื่อมต่อผ่านเซิร์ฟเวอร์สาธารณะของ PeerJS (ฟรี ไม่รับประกัน เครือข่ายบางแห่งที่เข้มงวดอาจต่อเสียงไม่ติด)
- **ขึ้นลิงก์ https (Render Static Site):** `render.yaml` ตั้งไว้แล้ว push โฟลเดอร์นี้ขึ้น GitHub แล้วที่ Render เลือก New → Blueprint ได้ลิงก์ `https://hotel-murder.onrender.com` (ชื่ออาจต่าง) หน้าแรกพาไป `app/online.html` เอง ถ้า Blueprint ไม่รับ ให้สร้าง Static Site เองแล้วตั้ง Publish directory เป็น `.` เว็บสแตติกไม่หลับเหมือน Web Service
- **สถานะ:** ทดสอบการเล่นจนจบด้วยเบราว์เซอร์ 2 แท็บและเทสต์จำลองหลายคนแล้ว แต่ **ยังไม่ได้ทดสอบเสียงจริงกับไมค์และคนจริง**

## ภาพรวมกติกา

- ทุกคนมี **ห้อง** ลับ (ชั้น × แถว 1–3 เช่น ห้อง 402) และ **บทบาท** ลับ โรงแรมใช้กี่ชั้นเท่าจำนวนผู้เล่น (สูงสุด 9) เปิดเกมมี **3 ห้องที่พบศพ** ปิดไว้
- **กลางคืน** (ตามลำดับ): ช่างกุญแจล็อก 1 ห้อง · แม่บ้านนับคนในชั้น · ช่างเช็ดกระจกนับคนในแถว · นักสืบรู้ชั้นของ 1 คน · ผู้ช่วยฆาตกรรู้ชั้นของ 1 คน · ฆาตกรเลือกห้องลงมือ · พยานเฝ้าชั้น (รู้ว่าห้องฆาตกรสูง/ต่ำกว่า ถ้าเฝ้าชั้นที่ฆาตกรเลือก)
- **กลางวัน:** คุยกัน (โกหกได้) เสนอห้องที่จะรุมบุก ยกมือโหวต ต้องมากกว่าครึ่งของคนที่ยังอยู่ ห้องว่างปิด ห้องที่มีคน เจ้าของออกจากเกม (ไม่เปิดบทบาท) ถ้าเป็นห้องฆาตกร ฝ่ายบริสุทธิ์ชนะ
- ฝ่ายฆาตกรชนะถ้ารอดครบ 4 วัน หรือถ้าจำนวนฝ่ายฆาตกรเท่ากับผู้บริสุทธิ์ที่เหลือ

## สิ่งที่ยังไม่ได้ทำ

- ไฟล์พิมพ์กติกา 1.0 สร้างแล้ว (การ์ดบทบาท คีย์การ์ด 27 ใบ กระดาน 9 ชั้น ป้าย ใบโฮสต์ ใบสรุปหลังเกม คู่มือผู้เล่น สคริปต์โฮสต์) ตรวจแล้วว่าแต่ละหน้าพอดี A4 แต่ **ยังไม่ได้ลองพิมพ์จริง** ควรพิมพ์ทดสอบหน้าการ์ดสองด้านว่าหน้า-หลังตรงกัน (generator v0.4 เดิมเก็บไว้ที่ `_archive_v0.4/tools/` และสำเนาไฟล์พิมพ์เดิมที่ `_archive_v0.4/print/`)
- `variant-clues/` ปรับตามกติกา 1.0 แล้ว (ร่าง 0.2) แต่ยังไม่เคยเล่นทดสอบ ฉบับเดิมเก็บไว้ที่ `variant-clues/_archive_v0.1/`
- ยังไม่ได้ลองเล่นกับคนจริง บอตไม่ได้คิดแบบมนุษย์ ผลชนะของบอตใช้เป็นแค่ตัวชี้ ไม่ใช่ค่าสมดุล
- ค่าที่คลิปไม่ได้บอก (บทบาทเมื่อเล่น 6/8/9 คน การประกาศห้องที่ถูกล็อก ผลโหวตเสมอ ฯลฯ) ควรตรวจกับกล่องจริงหรือคู่มือจริง
