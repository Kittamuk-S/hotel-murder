# โหมดหลักฐาน (เวอร์ชันทางเลือก, ร่าง 0.2)

เกมที่ **ไม่ต้องมีโฮสต์** บนกติกา 1.0: ฆาตกรลงมือที่ห้อง วางหลักฐานจริง 1 ชิ้นกับหลักฐานปลอมทุกคืน แขกทุกคนมีโปรไฟล์สาธารณะ (สีเสื้อผ้า ของติดตัว รองเท้า กลิ่น) แต่ห้องเป็นความลับ กลางวันใช้หลักฐาน แล็บ และกล้อง เพื่อหาห้องของฆาตกร แล้ว **เสนอห้องและโหวตรุมบุก** เหมือนกติกาหลัก (ไม่โหวตตัวคน)

- กติกา: `docs/RULEBOOK_TH.md`
- ข้อมูลและไฟล์พิมพ์: `data/`, `print/` (สร้างจาก `tools/build.py`) ส่วนกระดาน คีย์การ์ด และป้ายห้องใช้ของชุดหลัก `../print/`
- การจำลอง: `tools/sim_clues.py` พบว่าถ้าใช้หลักฐานอย่างเดียว ผู้ต้องสงสัยจะเหลือ 2 คนเสมอ (ฆาตกรกับแพะรับบาป) จึงต้องมีแล็บและกล้องวงจรปิดเพื่อตัดสิน
- ฉบับก่อนปรับ (ร่าง 0.1: สถานที่ 6 แห่ง กล่าวหาตัวคน เหรียญความน่าเชื่อถือ): `_archive_v0.1/`

สถานะ: ไม่เคยเล่นทดสอบ แขกเพิ่มเป็น 9 โปรไฟล์ (จัดชุดค่าใหม่ แต่ละคู่ซ้ำกันไม่เกิน 1 ค่า) เพื่อรองรับ 6–9 คนตามกติกา 1.0 ตัวเลขในกติกา (เวลา 4 นาที เหรียญอย่างละ 3) เป็นค่าตั้งต้นสำหรับ playtest
