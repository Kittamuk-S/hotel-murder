# สคริปต์โฮสต์ Hotel Murder (ตามกติกา 1.0)

พูดตามนี้ได้เลย เรียงตามลำดับ ตัวเอียงคือสิ่งที่โฮสต์ทำ

## เตรียมเกม
1. ปิดชั้นที่เกินจำนวนผู้เล่น (7 คนเล่นชั้น 1–7) *สุ่ม 3 ห้องที่พบศพ วางป้ายปิด ประกาศเลขห้อง*
2. แจกบทบาทและคีย์การ์ดลับ
3. “ทุกคนหลับตาครับ” → เรียกแต่ละบทบาทให้ลืมตาดูการ์ดของตัวเอง → “ผู้ช่วยและฆาตกรลืมตาครับ ชูคีย์การ์ดให้เห็นกัน” → ทุกคนหลับตา → “ลืมตาพร้อมกัน 3-2-1”

## กลางวัน (เริ่มที่วัน 1)
- (วัน 2 ขึ้นไป) “เมื่อคืนฆาตกรบุกไปที่ชั้น X ห้อง XXX” แล้วบอกอย่างใดอย่างหนึ่ง
  - “ห้องนี้มีผู้เสียชีวิตครับ กรุณาคืนคีย์การ์ด” (ไม่ถามบทบาท ไม่เปิดตัว)
  - “ห้องนี้ไม่มีคนอยู่ครับ”
  - “ประตูห้องนี้ล็อกอยู่ ลงมือไม่สำเร็จครับ”
- “เริ่มอภิปรายได้เลยครับ” *พลิกนาฬิกาทราย*
- หมดเวลา: “ขอเลขห้องที่จะรุมบุก 1 ห้องครับ”
- ทุกคนเสนอห้องได้ คนละไม่เกิน 1 ห้อง
- “ห้องที่เสนอมีดังนี้…” *ไล่จากเลขน้อยไปมาก* → “ถ้าเลือกบุกห้อง XXX ยกมือพร้อมกัน 3-2-1” → *นับ ต้องมากกว่าครึ่งของผู้ที่ยังอยู่*
- ถ้ามีห้องผ่านเสียงข้างมาก: *เปิดห้อง*
  - ห้องว่าง → “ห้องนี้ว่างครับ” *วางป้ายปิด*
  - มีคนอยู่ → “ห้องนี้มีคนอยู่ครับ กรุณาคืนคีย์การ์ดและออกจากเกม” (ไม่เปิดบทบาท)
  - เป็นห้องฆาตกร → “ฝ่ายบริสุทธิ์ชนะครับ!”
- ไม่มีห้องผ่าน: “วันนี้ไม่มีใครถูกบุกครับ”
- *ตรวจ* ถ้าฝ่ายฆาตกรเท่ากับผู้บริสุทธิ์ที่เหลือ ประกาศ “ฝ่ายฆาตกรชนะครับ”
- จบวัน 4 โดยไม่เจอห้องฆาตกร: “ฆาตกรหนีไปได้ ฝ่ายฆาตกรชนะครับ”

## กลางคืน (หลังวัน 1, 2, 3)
“ทุกคนหลับตาครับ” แล้วเรียกตามลำดับ (เรียกบทที่ตายแล้วด้วย แต่ไม่ต้องรอให้เขาทำอะไร เพื่อไม่ให้ใครรู้ว่าใครตาย)

1. **ช่างกุญแจ** ลืมตาครับ เลือกล็อก 1 ห้องให้ปลอดภัย (ห้ามซ้ำกับคืนก่อน) → หลับตา
2. **แม่บ้าน** ลืมตาครับ เลือกตรวจ 1 ชั้น → *บอกจำนวนผู้ที่ยังมีชีวิตในชั้นนั้น* → หลับตา
3. **ช่างเช็ดกระจก** ลืมตาครับ เลือกตรวจ 1 แถวแนวตั้ง → *บอกจำนวนผู้ที่ยังมีชีวิตในแถวนั้น* → หลับตา
4. **นักสืบ** ลืมตาครับ เลือก 1 คน → *บอกชั้นที่คนนั้นพัก* → หลับตา
5. **ทีมฆาตกร** ลืมตาครับ
   - ผู้ช่วยเลือก 1 คน → *บอกชั้น*
   - ฆาตกรเลือก 1 ห้องเพื่อฆาตกรรม (ห้ามห้องตัวเอง/ผู้ช่วย/ห้องที่ปิด) *จดไว้*
   - ทีมฆาตกรหลับตา
6. **พยาน** ลืมตาครับ เลือกเฝ้า 1 ชั้น → ถ้าตรงกับชั้นที่ฆาตกรเลือก *บอก สูงกว่า / ต่ำกว่า / ชั้นเดียวกัน (เทียบ “ห้องของฆาตกร” กับชั้นที่เฝ้า)* ถ้าไม่ตรง *ไม่บอกอะไร* → หลับตา

จากนั้น “ตื่นพร้อมกัน 3-2-1” แล้วประกาศเหตุการณ์ตามหัวข้อกลางวัน

## ที่โฮสต์ต้องจดไว้
ห้องที่ล็อกของคืนก่อน · ห้องที่ปิดแล้ว · ผู้ที่ออกจากเกม · เลขวัน (1–4)
